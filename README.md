# Flipper Zero Games

A small collection of games I've built for the [Flipper Zero](https://flipperzero.one/).
Each folder below is its own self-contained app — pick one and follow the
README inside it to install or build it.

| Game | Description |
|---|---|
| [🧠 Memory Game](memory-game/) | A Simon-Says style memory game — watch the pattern, repeat it, see how far you get. |

More games will be added here over time.
